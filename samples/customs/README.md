# Sample Customs packet (for live testing the audit)

One coherent, internally-consistent shipment — laptops from **Acme Manufacturing Ltd**
(Shenzhen, China) to **Globex Imports Inc** (San Francisco, USA) — rendered two ways so
you can exercise **both** intake paths:

- `digital/*.pdf` — real text-layer PDFs → the router's **text path** (cheap, lite model).
- `scanned/*.png` — rasterized, slightly skewed + speckled "scans" with **no** text layer
  → the router's **multimodal path** (Gemini vision). This is the path to validate.
- `combined/packet_digital.pdf` and `combined/packet_scanned.pdf` — **all four documents in
  one file** (one per page), text-layer and scanned respectively. These test that a combined
  packet is split into its constituent documents rather than read as a single document.

The four documents (commercial invoice, packing list, bill of lading, certificate of
origin) are mutually consistent: HTS `8471.30.0100`, origin China, value 10000.00 USD,
net weight 500 kg, 20 cartons, same exporter/consignee throughout.

## Test scenarios

1. **All digital** — upload the 4 files in `digital/` → expect **CLEAR** (validates the
   text path end to end).
2. **All scanned** — upload the 4 files in `scanned/` → the key test: does the multimodal
   path classify + extract correctly? Expect **CLEAR** (or a few `needs_review` if a scan
   reads imperfectly — which is the safety valve working, not a failure).
3. **Mixed** — some PDFs + some PNGs in one packet → confirms per-file routing.
4. **Missing document** — omit `certificate_of_origin` → expect it under **MISSING**.
5. **Deficient** — drop in a file whose HTS code is malformed or whose totals disagree →
   expect **DEFICIENT** (easy to fake by editing a `digital/*.pdf` source).
6. **Combined packet** — upload the single `combined/packet_scanned.pdf` (or
   `packet_digital.pdf`) → expect all four documents recognized (not just the first page).

> Generated by `scripts` using fpdf2 + Pillow; regenerate anytime. These are fixtures,
> not real trade documents.
